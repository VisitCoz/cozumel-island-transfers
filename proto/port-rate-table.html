The rule, in one picture
  1. Published means the day is inside the window the port authority currently shows. On 19 September that window ends on the 26th.
  2. Month average is the ships-per-day figure in data/port-month-averages.json, built from Sep 2025 to Sep 2026. It is rounded to the nearest whole ship before the ladder reads it: September's 2.45 reads as 2 ships, so an unpublished September day earns 20%.
  3. Deep tiers (20% and 25%) exist only for the Private van and the Large private van, and only May to October.
Two things for you to confirm 1 · The builder script lives in scripts/build_port_averages.py. The brief did not list scripts/ as touchable; I added it anyway so the data file can be rebuilt each season. Say so if you'd rather not.
2 · Cancelled calls (the port's red marker) are not counted as ships in port. The research page counted them, which is why its month totals run one to six calls higher, and why January averages 11.6% here against the page's 10.8%.
3 · Found and fixed while wiring this: the live scraper behind "ships in port today" was dropping the first ship of every day (the port's date-header row has no closing tag). The homepage count has been one short every day. The fix ships with this branch.
